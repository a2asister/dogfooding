# 大学门户网站与学生后台系统 - 产品需求文档 (PRD)

## 1. 项目概述

### 1.1 项目背景
本项目旨在构建一个完整的大学信息化管理系统，包含面向公众的门户网站和面向学生的后台管理系统，实现学校信息展示与学生日常事务管理的一体化平台。

### 1.2 项目目标
- 搭建统一的学校门户网站，展示学校形象与公共信息
- 构建学生后台管理系统，支持学生日常学习与生活事务
- 实现统一身份认证与权限管理体系
- 提供完整的模拟数据以支撑系统展示与测试

### 1.3 目标用户
- **门户网站访客**：社会公众、考生、家长、校友
- **学生后台用户**：在校学生

---

## 2. 功能需求

### 2.1 门户网站 (Portal)

| 模块 | 功能描述 |
|------|----------|
| **首页** | 学校概况轮播、新闻快讯、重要通知、快速入口导航 |
| **学校概况** | 学校简介、历史沿革、现任领导、校园风光 |
| **新闻动态** | 校园新闻列表、新闻详情、公告通知 |
| **招生就业** | 招生简章、招生计划、就业指导、招聘信息 |
| **教学科研** | 院系设置、师资力量、科研成果、学术交流 |
| **公共服务** | 办事指南、联系我们、校园地图、常用下载 |
| **统一登录** | 登录入口跳转至学生后台认证页面 |

### 2.2 学生后台系统 (Student Portal)

#### 2.2.1 基础能力
- 统一身份认证登录
- 基于角色的权限管控
- 会话超时自动登出
- Token 刷新机制

#### 2.2.2 业务功能

| 模块 | 功能描述 |
|------|----------|
| **首页工作台** | 待办事项、今日课表、成绩概览、校园日历、通知公告 |
| **课表查询** | 周课表展示、课程详情、教室信息、教师信息 |
| **成绩查询** | 学期成绩列表、成绩详情、绩点计算、成绩排名 |
| **基础选课** | 可选课程列表、已选课程、选课/退课操作、冲突检测 |
| **期末评教** | 待评教课程列表、评教表单提交、评教历史 |
| **消息中心** | 系统通知、个人消息、消息已读/未读状态、消息分类 |
| **学籍信息** | 个人基本信息、学籍状态、培养方案、奖惩记录 |
| **账号安全** | 密码修改、绑定手机/邮箱、登录记录、安全设置 |

## 3. 非功能需求

### 3.1 技术栈
- **前端**：React 18 + TypeScript 5 + Vite
- **后端**：Koa 2 + TypeScript + SQLite
- **构建工具**：concurrently 并发启动前后端

### 3.2 代码质量
- TypeScript 严格模式 (strict: true)
- ESLint 代码规范校验
- Prettier 代码格式化

### 3.3 端口配置
- 前端端口：5173 (Vite 默认)
- 后端端口：8765 (不常用端口)

### 3.4 性能要求
- 页面首屏加载时间 < 3s
- API 响应时间 < 500ms
- 支持 1000+ 并发用户

## 4. 数据模型 (核心实体)

### 4.1 用户体系
- User (用户)：id, studentId, name, password, role, status
- Session (会话)：id, userId, token, expireAt, userAgent

### 4.2 教学数据
- Course (课程)：id, name, teacher, credit, time, location, capacity
- Schedule (课表)：id, userId, courseId, weekDay, period
- Grade (成绩)：id, userId, courseId, score, gradePoint, semester
- Selection (选课)：id, userId, courseId, status, createTime

### 4.3 其他数据
- News (新闻)：id, title, content, category, publishTime
- Message (消息)：id, userId, title, content, type, isRead
- Evaluation (评教)：id, userId, courseId, score, comment, createTime

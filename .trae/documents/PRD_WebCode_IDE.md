## 1. 产品概述
WebCode IDE 是一个轻量级的在线代码编辑器，专为前端开发者设计，提供实时预览和热更新功能。
- 核心目的：让用户在浏览器中快速编写、预览和调试 HTML/CSS/JavaScript 代码
- 目标用户：前端开发者、学习者、教育工作者
- 产品价值：零安装、即开即用、实时反馈、便于分享和学习

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 使用所有编辑和预览功能 |

### 2.2 功能模块
1. **主界面**：顶部菜单栏、左侧文件树、中间编辑器、右侧预览区
2. **文件管理**：新建、重命名、删除文件，多文件切换
3. **代码编辑**：语法高亮、代码提示、格式化
4. **实时预览**：右侧预览区，代码修改自动热更新
5. **项目管理**：本地缓存自动保存、下载为 ZIP 包

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主界面 | 顶部菜单栏 | 文件操作（新建/保存/下载）、运行预览、帮助信息 |
| 主界面 | 文件树 | 显示项目文件列表，支持新建/重命名/删除 |
| 主界面 | 代码编辑器 | 基于 Monaco Editor，支持 HTML/CSS/JS 语法高亮和提示 |
| 主界面 | 预览区 | iframe 实时渲染，支持热更新 |

## 3. 核心流程
用户打开 WebCode IDE → 自动加载本地缓存项目 → 在编辑器中编写代码 → 预览区实时更新 → 通过菜单栏下载项目为 ZIP

```mermaid
    E --> F["自动保存到本地"]

```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝 #1e1e1e（编辑器背景）、亮蓝 #007acc（强调色）
- **辅助色**：浅灰 #d4d4d4（文本）、深灰 #252526（侧边栏）
- **按钮风格**：扁平化、圆角 4px、悬停有轻微亮度变化
- **字体**：JetBrains Mono（代码）、Inter（界面文本）
- **布局风格**：经典 IDE 三栏布局，顶部菜单栏
- **图标风格**：简约线性图标，使用 VSCode 风格

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主界面 | 顶部菜单栏 | 深色背景、白色文字、下拉菜单 |
| 主界面 | 文件树 | 文件夹图标、文件名、右键菜单 |
| 主界面 | 代码编辑器 | 行号、语法高亮、折叠箭头 |
| 主界面 | 预览区 | iframe 边框、刷新按钮、地址栏模拟 |

### 4.3 响应式
- 桌面端优先设计，支持窗口大小调整
- 编辑器和预览区支持拖拽调整宽度
- 小屏幕下可切换单栏模式

### 4.4 动效设计
- 文件切换时的淡入淡出过渡
- 代码修改时预览区的平滑更新
- 菜单栏下拉的滑入动画
- 按钮悬停的微妙缩放效果
